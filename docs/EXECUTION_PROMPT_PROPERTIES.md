# پرامپت اجرایی دقیق — فاز تکمیل فایلینگ در پیش‌نمایش

## متن پرامپت مورد استفاده

> در مخزن موجود ملکینو، فقط جریان مدیریت فایل ملک را در پیش‌نمایش React/TypeScript تکمیل کن. ابتدا ساختار و داده‌های موجود را بررسی کن و قابلیت‌های سالم را حفظ کن. عملیات ایجاد، ویرایش، بایگانی/بازگردانی، جست‌وجو، فیلتر و خروجی CSV را در محدوده فعلی پیاده کن؛ ورودی عددی فارسی/عربی را اعتبارسنجی کن، شناسه فایل را یکتا نگه‌دار و ذخیره مرورگر را در برابر JSON خراب مقاوم کن. برای منطق دامنه تست واحد بنویس و RED/GREEN را ثبت کن. رابط RTL، واکنش‌گرا و قابل استفاده با صفحه‌کلید بماند. داده نمونه و ذخیره مرورگر را صریحاً از Backend واقعی متمایز کن. احراز هویت، API، دیتابیس، RLS یا قابلیت ماژول‌های دیگر را شبیه‌سازی یا ادعای تکمیل نکن. هیچ اتصال خارجی و هیچ پروژه Supabase نامرتبطی را تغییر نده. در پایان build، تست‌ها و محدودیت‌های باقی‌مانده را گزارش کن.

## دامنه و معیار پذیرش
- فایل جدید با فیلدهای ضروری، اعتبارسنجی سمت UI/domain و اعداد فارسی ثبت شود.
- ویرایش فایل، کد فایل را تغییر ندهد و داده‌های دیگر را دست‌نخورده نگه دارد.
- بایگانی و بازگردانی، وضعیت پیشین فایل را حفظ کند.
- جست‌وجو/فیلتر و شمارنده‌ها با مجموعه واقعی فایل‌های همین مرورگر هماهنگ باشند.
- CSV با UTF-8 BOM برای Excel فارسی صادر و سلول‌ها escape شوند.
- داده خراب localStorage باعث crash یا overwrite خودکار نشود.
- تست واحد و build سبز باشند.

## Skills انتخاب‌شده از مخزن Agent
- `kit/skills/tdd-workflow`: تست منطق فایل پیش از تکمیل implementation.
- `kit/skills/react-patterns` و `kit/agents/react-reviewer`: state immutability، hook cleanup و بررسی تعاملات React.
- `kit/skills/frontend-design-direction`: اولویت داشبورد عملیاتی، زبان بصری آرام و حالت‌های قابل‌تشخیص.
- `kit/skills/accessibility`: نام‌گذاری کنترل‌ها، فوکوس آشکار، RTL و ابعاد قابل‌کلیک.
- `kit/skills/security-review`: ورودی کاربر و مرز واضح بین ذخیره محلی و سرویس واقعی.

مخزن `rahmaniho/Skill` که بررسی شد، مهارت Google Maps scraper برای تولید لید کسب‌وکار محلی دارد؛ این موضوع با فایلینگ آژانس املاک یکی نیست و این فاز به‌درستی آن را اجرا یا به اپ متصل نمی‌کند.
