# نیازمندی‌های محصول — ملکینو

## هدف
سامانه فارسی و RTL برای مدیریت عملیات آژانس املاک ایران، از ثبت فایل تا پیگیری مشتری، بازدید، معامله و مالی.

## کاربران اصلی
مالک آژانس، مدیر شعبه، مدیر فروش، مشاور، حسابدار و پذیرش. دسترسی مشتری/مالک فقط پس از تعریف مجزا و امن.

## پیاده‌سازی عملیاتی فعلی
- فایلینگ ملک متصل به API: فهرست، جست‌وجو/فیلتر، ثبت، ویرایش، تغییر وضعیت، بایگانی/بازگردانی و CSV.
- CRM پایه متصل به API: دفتر مخاطبان، اطلاعات تماس و نیاز/بودجه، جست‌وجو، مراحل پیگیری، ویرایش، بایگانی/بازگردانی و CSV.
- پیگیری‌های CRM متصل به API: تماس، جلسه، بازدید ملک و یادآوری؛ ثبت از فرم تقویم یا مستقیم از ردیف مشتری، فهرست، تکمیل/لغو و audit.
- ورود کاربر با Supabase Auth؛ tenant/branch-scoped backend و RLS.
- داشبورد فقط از داده واقعی API آمار می‌سازد؛ بدون env صفحه راه‌اندازی نمایش داده می‌شود.
- رابط responsive فارسی RTL، فونت Vazirmatn و لوگو/آیکون برنامه از دارایی‌های مخزن.

## نیازمندی‌های محصول کامل (هنوز پیاده‌سازی نشده)
تطبیق مشتری-ملک، فعالیت و یادآوری/تماس، بازدیدها، معاملات و قراردادها، مالی و کمیسیون، مدیریت تیم/عضویت، تقویم، اسناد، بازاریابی، گزارش‌های پیشرفته، اشتراک SaaS و AI کنترل‌شده.

## معیارهای پذیرش فازهای عملیاتی
- تمام فایل‌ها و مخاطبان از API خوانده/نوشته شوند؛ هیچ داده نمونه یا localStorage برای رکوردها استفاده نشود.
- احراز هویت و مجوزها در Backend بررسی شوند؛ جداسازی tenant/branch با تست RLS پوشش یابد.
- پول با واحد صریح و بدون float نگهداری شود؛ CSV داده‌های حساس غیرضروری را صادر نکند.
- رابط در موبایل قابل استفاده و فارسی RTL باشد؛ بخش پیاده‌سازی‌نشده ادعای عملکرد واقعی نکند.
