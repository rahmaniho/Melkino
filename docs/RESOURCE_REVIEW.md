# بررسی منابع Agent و Skill

این منابع برای تصمیم‌های اجرایی همین مخزن مرور شدند؛ هیچ مخزن خارجی به‌صورت dependency یا submodule وارد پروژه نشده است.

## `rahmaniho/Agent`
- مهارت `kit/skills/frontend-design-direction`: برای طراحی محصول‌محور و dashboard روزمره؛ خروجی با سلسله‌مراتب قابل‌اسکن، ابزارهای واقعی در اولین صفحه، استایل مینیمال و آرام، responsive و پرهیز از صفحه‌ی بازاریابی/کارت‌های تزئینی ساخته شد.
- مهارت `kit/skills/accessibility`: استفاده از HTML معنایی، labelهای قابل‌فهم برای کنترل‌های آیکونی، فوکوس صفحه‌کلید، اندازه هدف قابل‌کلیک و چیدمان موبایل لحاظ شد؛ انطباق رسمی WCAG یا آزمون screen reader ادعا نمی‌شود.
- مهارت `kit/skills/react-patterns` و مرورگر `kit/agents/react-reviewer`: state به رویدادهای UI محدود شده، listener میان‌بر صفحه‌کلید cleanup دارد و مقادیر نمایشی مشتق‌شده در render محاسبه می‌شوند. `npm run build` با TypeScript strict تأیید شد.
- راهنمای `kit/rules/web/design-quality.md` نیز برای طراحی قابل‌تشخیص در حوزه املاک و استفاده از نشانه‌های دیداری مرتبط به‌جای تزئینات بی‌هدف مدنظر قرار گرفت.

## `rahmaniho/Skill`
مهارت منتشرشده‌ی این مخزن `google-maps-scraper` برای استخراج لید کسب‌وکارهای محلی از Google Maps است؛ با فایلینگ ملک و مدیریت عملیات آژانس یکی نیست. در این UI، اسکرپ، استخراج شماره/شبکه اجتماعی، جمع‌آوری داده از اشخاص یا ارسال خودکار پیام اضافه نشده است. اگر در آینده قابلیت جذب سرنخ لازم شود، باید جداگانه با منبع مجاز، رضایت/مبنای حقوقی، حداقل‌سازی داده و اتصال واقعی ارزیابی شود؛ شبیه‌ساز scraper جای API واقعی نخواهد بود.
